## Notes for the report

- Promotion of known-good copies is event-driven, not timer-driven; a legit edit made well before an attack still survives because `note_alert` promotes due copies before restore. Idle-timer promotion is a possible future fix.
- Isolation: each test uses its own temporary sandbox, database, log and backups; the real `main.py` start-up path is covered by a manual live run.
- S6 switches attribution off through the watcher's own `attribute` flag, not a production hook.
